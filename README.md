# Potato-Disease-Identification-Using-Deep-Learning
Potato Disease Identification Using Deep Learning is a system that detects and classifies potato leaf diseases from images using deep learning models. It helps farmers identify diseases early and improve crop yield through accurate and automated analysis

## ✨ Features

- 📷 Upload potato leaf images
- 🤖 Automated disease detection using CNN
- 🌿 Classifies healthy and diseased potato leaves
- 📊 Displays prediction results with confidence score
- 🖥️ User-friendly web interface


## 🛠️ Tech Stack

- **Programming Language:** Python
- **Deep Learning:** TensorFlow, Keras
- **Image Processing:** OpenCV
- **Frontend:** HTML, CSS, JavaScript
- **Tools:** Git, GitHub, VS Code
